## About the Project

This project demonstrates a basic HTML form that collects:

* Name
* Email
* Address

The submitted information is stored in the browser using JavaScript localStorage and then displayed on a separate page.

##  Project Structure

registration-form/
│
├── index.html       # Registration form
├── Details.html     # Displays submitted information
└── README.md        # Project documentation

## How It Works

Open index.html.

Enter your name, email, and address.

Click Submit.

JavaScript stores the entered information in localStorage.

The browser navigates to Details.html.

Details.html retrieves the stored information and displays it.
